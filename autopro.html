AutoPro

Premium Adobe Scripts Plugin for Adobe Photoshop and Illustrator. Automate your creative workflow and login to access free powerful scripts.

Download Plugin

Windows Users (Easiest Way)

  • Simply double-click the "Install_AutoPro_Windows.bat" file.
  • Windows will ask for Administrator permission (User Account Control). Click "Yes".
    (This is required to copy the files to your Adobe C: drive folder).
  • The command prompt will automatically install the plugin for you.
  • Open Adobe Illustrator/Photoshop, go to Window > Extensions > Pro Scripts Login.

Mac Users (Or Alternative Windows Way)

  • Download Anastasiy's Extension Manager:
    Mac: https://install.anastasiy.com/ExtensionManager_latest_mac.dmg
    Win: https://install.anastasiy.com/ExtensionManager_latest_win.zip
  • Open Anastasiy's Extension Manager and click "Install".
  • Select the "AutoPro_v1.0.0.zxp" file.
  • Open Adobe Illustrator/Photoshop, go to Window > Extensions > Pro Scripts Login.

How to Uninstall (Windows Only)

  • Double-click the "Uninstall_AutoPro_Windows.bat" file.
  • Windows will ask for Administrator permission. Click "Yes".
  • It will completely remove the plugin from your PC.

NOTE: Do NOT separate the files in the downloaded folder. The "Install_AutoPro_Windows.bat" file needs the "extension" folder to work properly!
