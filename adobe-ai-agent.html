Adobe AI Agent

Prompt-driven AI Agent extension for Adobe Photoshop and Illustrator. Just describe what you want to create and let the agent build it automatically inside your document.

Download Plugin

Windows Users (One-Click Installer)

  • Extract the downloaded ZIP completely into a folder.
    (Do not run from inside the ZIP preview — keep the "extension" folder next to the installer).
  • Double-click the "Install_AdobeAIAgent_Windows.bat" file.
  • Windows will ask for Administrator permission (User Account Control). Click "Yes".
    (This is required to copy the extension files into your Adobe C: drive folder).
  • Restart Adobe Photoshop or Illustrator, then open:
    Photoshop: Window > Extensions (legacy) > Adobe AI Agent
    Illustrator: Window > Extensions > Adobe AI Agent

Mac Users (Or Extension Manager / ZXP)

  • Download Anastasiy's Extension Manager (or ZXPInstaller):
    Mac: https://install.anastasiy.com/ExtensionManager_latest_mac.dmg
    Win: https://install.anastasiy.com/ExtensionManager_latest_win.zip
  • Open Anastasiy's Extension Manager and click "Install" (or drag & drop into ZXPInstaller).
  • Select the ".zxp" file from the extracted folder.
  • Restart Adobe Photoshop or Illustrator and open Window > Extensions > Adobe AI Agent.

First-Time Login & API Key Setup

  • Click "Sign in with Google" inside the Adobe AI Agent panel and approve login in your browser.
  • Return to Photoshop/Illustrator and open the API Keys modal inside the panel.
  • Paste your own Gemini / OpenAI / Grok / Mistral API key.
  • Start chatting! Describe what you want to create and the agent will build it directly in your workspace. Daily credits reset automatically every midnight (12:00 AM BD Time).

How to Uninstall (Windows Only)

  • Double-click the "Uninstall_AdobeAIAgent_Windows.bat" file.
  • Windows will ask for Administrator permission. Click "Yes".
  • It will completely remove the plugin from your PC.

NOTE: Do NOT separate the files in the extracted folder. The "Install_AdobeAIAgent_Windows.bat" file needs the "extension" folder in the same directory to work properly!
