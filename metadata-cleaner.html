Offline Metadata Cleaner

A fast, privacy-focused offline tool to securely remove EXIF data from your assets. Powered by ExifTool.

Download Tool

এই টুল দিয়ে যেকোনো folder-এ right-click করলেই সব image ও video file-এর metadata clean হয়ে যাবে। ColorSpace tag preserve থাকবে।

Install করতে

  • "Install.bat" ফাইলে Right-click করুন
  • "Run as administrator" সিলেক্ট করুন
  • UAC prompt আসলে "Yes" দিন
  • ব্যস! Installation complete!

ব্যবহার

  • যেকোনো folder-এ right-click করুন
  • "🧹 Clean Metadata"-এ ক্লিক করুন
  • CMD window-তে progress দেখাবে
  • কাজ শেষ হলে any key press করুন

Windows 11 এ:

Right-click → "Show more options" → "🧹 Clean Metadata"

Supported Formats

Images:
jpg jpeg png
Videos:
mp4 avi mov mkv wmv flv webm

Uninstall করতে

  • "Uninstall.bat" ফাইলে Right-click করুন
  • "Run as administrator" সিলেক্ট করুন
  • Y টাইপ করে Enter দিন
